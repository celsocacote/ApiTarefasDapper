# API de Tarefas com Dapper

Primeira API REST feita estudando C# com Macoratti.

## Stack
- .NET 8
- ASP.NET Core Minimal API
- Dapper
- SQL Server

## Como rodar
1. Clone o repo
2. Ajuste a connection string em `appsettings.json`
3. Roda `dotnet run`
